# Changes on 2026-10-07

## Streamlit workspace: shared review and six column uploads

The Streamlit workspace now follows the same rules as the Data Harmonizer tab in the Gradio app.

### Uploaded files
- Uploaded CSV and Excel files must contain construct, questionnaire, item_id, item_text, answer_options and scoring. The column mapping step now asks for all six.
- Empty cells in any of the six columns are rejected, as for manual entries.
- Items taken from the reference inventory still need only the first four columns.
- The input template now has the six columns and example values.

### Possible duplicates
- Uploaded files and reference items now get the same duplicate review that manual entries already had. It appears in the Inventory check step.
- Each possible duplicate has a `same_item?` checkbox, checked by default. Checked items reuse the inventory assignment. Unchecked items go to the model as new items.
- `same_item?` is the first column of the table in both the manual and the upload flow.
- The review lives in one shared function, so both flows behave the same way.
- Overview cards and the routing summary now count items confirmed as the same item as reused, and show how many duplicates were kept as new.

### Results and inventory
- Results for uploaded files carry answer_options and scoring.
- Reused matches write nothing to the inventory. Only new model predictions are appended, as before.

### Tests
- New tests cover the six column rule for uploads, the first four column rule for reference items, the default and unchecked reuse decisions, and reading decisions from the review table.
